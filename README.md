🐍 Snake Game – After Hours

A simple, modern Snake Game built using HTML, CSS, and JavaScript. Play directly in your web browser!

🎮 Features

- Classic snake gameplay
- Keyboard controls using Arrow Keys or WASD
- Touch controls for mobile devices
- Score tracking
- High score saved using Local Storage
- Pause and resume functionality
- Increasing difficulty as you level up
- Dark-themed user interface

🛠️ Technologies Used

- **HTML5** – Game structure
- **CSS3** – Styling and layout
- **JavaScript** – Game logic and controls
- **Canvas API** – Game rendering
- **Local Storage** – Saving the best score

🚀 How to Play

1. Open the game in your browser.
2. Use the **Arrow Keys** or **WASD** to control the snake.
3. Eat the food to increase your score.
4. Avoid hitting the walls or the snake's own body.
5. Try to beat your high score!

2. Open `index.html` in your web browser.
